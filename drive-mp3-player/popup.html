      Playback

      On: when a file ends, the next file in the list you chose starts by itself. Off: playback stops after each file and you press ▶ for the next one. Audio never starts without a Play press, apart from this continuation.

      Save files for offline listening

      Files you choose with the ☑ button are always saved. Off (default): a single file you press plays temporarily from memory and leave nothing on disk, but replaying needs a new download and offline listening is unavailable. On: files are saved for offline listening and removed automatically by the cleanup rules below.

      Automatic cleanup

      When the limit is exceeded, the least recently played files are deleted first. Files uploaded from your computer (not on Drive) and the most recently played track are never deleted automatically.
